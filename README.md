# LexAI — Интеллектуальный переводчик и анализатор лексики

LexAI представляет собой современное веб-приложение, предназначенное для контекстного перевода текстов и проведения глубокого лексического анализа. Инструмент использует возможности OpenRouter API для обеспечения высококачественного перевода между русским, английским и казахским языками, а также детального разбора семантики переведенного текста.

## Ключевые возможности

### Контекстный перевод текста
Система обеспечивает точный и осмысленный перевод между русским, английским и казахским языками. Благодаря использованию современных языковых моделей ИИ, переводы сохраняют оригинальный смысл и контекст.

### Глубокий лексический анализ
Приложение не просто переводит текст, но и предоставляет подробный разбор ключевых слов и грамматических конструкций. Это позволяет пользователям лучше понимать структуру изучаемого языка и обогащать свой словарный запас.

### Безопасная авторизация пользователей
Для защиты пользовательских данных внедрена надежная система регистрации и входа с использованием электронной почты и пароля. Данный функционал реализован на базе Firebase Authentication.

### Облачная история переводов
Все выполненные переводы надежно сохраняются в базе данных Firestore. История поддерживает пагинацию для удобного просмотра и имеет механизм локального сохранения данных на случай отсутствия подключения к интернету.

### Современный и адаптивный интерфейс
Пользовательский интерфейс разработан с учетом всех современных стандартов доступности и адаптивности. Приложение поддерживает как светлую, так и темную темы оформления, автоматически подстраиваясь под предпочтения пользователя.

## Архитектура и технологии

### Frontend-часть
Клиентская часть приложения построена на чистых веб-технологиях: HTML5, CSS3 с использованием Grid и Flexbox, а также Vanilla JavaScript (ES6+). Для работы с данными и аутентификации используется Firebase SDK v9.

### Backend-часть
Серверная логика реализована на легком фреймворке Flask. Для взаимодействия с языковыми моделями применяется OpenAI Python SDK, настроенный на работу с OpenRouter API. Безопасность и стабильность работы обеспечиваются модулями Flask-Limiter для ограничения частоты запросов и Flask-CORS. В рабочей среде используется WSGI-сервер Gunicorn.

## Инструкция по развертыванию проекта

### Предварительные требования
Для успешного запуска проекта на вашем компьютере должен быть установлен Python версии 3.8 или выше. Также вам потребуется действительный API-ключ от сервиса OpenRouter и созданный проект в Firebase с активированными функциями Authentication и Firestore.

### Настройка серверной части (Backend)
Перейдите в директорию `backend` и создайте виртуальное окружение с помощью команды `python -m venv venv`. Активируйте его (на Windows это `venv\Scripts\activate`, на Linux/macOS — `source venv/bin/activate`). Затем установите необходимые зависимости, выполнив `pip install -r requirements.txt`. В папке `backend/` создайте файл `.env` и укажите в нем переменные: `OPENROUTER_API_KEY`, `MODEL_NAME`, `FLASK_DEBUG=True` и `PORT=5000`.

### Настройка клиентской части (Frontend)
Откройте файл конфигурации `frontend/js/firebase-config.js` и обновите объект `firebaseConfig`, вставив туда актуальные учетные данные вашего проекта Firebase, такие как `apiKey`, `authDomain`, `projectId` и другие.

### Запуск приложения
Для запуска сервера для разработки выполните команду `python main.py` в директории `backend`. Приложение будет доступно в браузере по адресу `http://localhost:5000`. Backend на Flask автоматически настроен на раздачу статических файлов frontend-части. Для развертывания в рабочей (production) среде рекомендуется использовать Gunicorn с помощью команды `gunicorn -w 4 -b 0.0.0.0:5000 main:app`.

## Безопасность и ограничения системы

### Лимитирование запросов
Для предотвращения перегрузок и злоупотреблений, API строго ограничивает количество запросов до 60 обращений в минуту с одного IP-адреса.

### Валидация полезной нагрузки
Объем входного текста для перевода строго лимитирован. Максимально допустимая длина одного запроса составляет 5000 символов.

### Политика CORS
Обмен ресурсами между разными источниками (CORS) корректно настроен на уровне сервера, что предотвращает несанкционированный доступ к API со сторонних доменов.
